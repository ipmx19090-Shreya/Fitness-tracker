# TrainTrack Fitness Tracker

A lightweight trainee dashboard for weekly workouts, nutrition, and daily habits.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. GitHub will provide the live URL.

## Notes

- Workout and habit check-offs are stored in browser `localStorage`.
- The current nutrition and workout values are demo content and should be replaced with each trainee's individualized plan.
